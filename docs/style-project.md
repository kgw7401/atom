## 하려는 것

복서의 **파이팅 스타일을 공간 데이터로 분류**한다.

아웃복서·슬러거·스워머는 원래부터 공간 전략의 분류다. 던지는 펀치 종류가 아니라
**어느 거리에서 싸우고 거기에 어떻게 도달하느냐**로 정의된다.
그러면 스타일은 라벨로 붙일 게 아니라 **공간 데이터에서 나와야 한다.**

## 선행 연구 — 공백이 구체적이다

| 분야 | 상태 |
|---|---|
| MMA 스타일 군집화 | 있음. K-means + 요인분석 |
| 팀 스포츠 스타일 분류 방법론 | 성숙함. PCA(44%) + K-means. [2025 체계적 리뷰](https://journals.sagepub.com/doi/10.1177/17479541251372586) 25편 |
| 복싱 경기 통계 | 있음. [CompuBox](https://en.wikipedia.org/wiki/CompuBox), 1985년부터. **펀치 개수만** |
| **공간 데이터 기반 스타일 분류** | **없음** |

### 기존 연구가 쓰는 것은 박스스코어다

MMA 스타일 군집화는 전부 **펀치 수, 명중률, 테이크다운 시도** 같은 집계 통계를 쓴다.
그건 "무엇을 했나" 다.

복싱이 말하는 스타일은 "어디서 싸우나" 다. 둘은 다른 것이다.
**아웃복서와 스워머가 똑같은 잽 개수를 던질 수 있다.** 차이는 그 잽을 던진 거리다.

### 리뷰 자신이 이 방향을 권고한다

위 2025년 체계적 리뷰가 향후 과제로 꼽은 것:

> 더 상세하고 해석 가능한 분석을 위해 **시공간 추적 데이터**를 쓸 것

우리가 하려는 게 정확히 그것이고, 대상이 아직 아무도 안 한 복싱이다.

리뷰가 지적한 문제도 새겨둘 만하다.

> 특징 선택·전처리·보고 방식이 연구마다 제각각이라 **재현성과 비교 가능성이 떨어진다**

그래서 이 프로젝트는 **어떤 값을 왜 골랐는지**를 문서에 남기는 것을 규칙으로 한다.

## 결정적 제약 — 중계 영상은 카메라가 움직인다

우리 파이프라인은 **고정 카메라**를 전제한다. 프로 경기 영상은 카메라가 팬·줌하고
컷이 바뀐다. 층별로 영향이 다르다.

| 층 | 중계 영상 | 이유 |
|---|---|---|
| **1. 거리** | **됨** | 몸 기준 정규화라 줌·팬에 불변. 두 사람이 같이 커지고 같이 움직인다 |
| **2. 움직임** | **절반** | 거리 변화(접근/후퇴)는 된다. 링 위 절대 이동은 카메라 움직임과 섞인다 |
| **3. 링** | **막힘** | 링 어디인지 알려면 매 프레임 링 위치를 보정해야 한다 |
| **4. 각도** | **됨** | 어깨 방향은 한 프레임 안에서 결정된다 |

**몸 기준 정규화가 1층을 살렸다.** 미터로 쟀다면 카메라가 줌할 때마다 값이 흔들려
중계 영상은 아예 쓸 수 없었다.

남은 문제:

- **컷 전환** — 앵글이 바뀌면 추적이 끊긴다. 컷 경계를 잡고 다시 붙여야 한다.
  1단계에서 확인했듯 **상의 색**이 강력한 재식별 단서다
- **앵글 변화** — 카메라가 링 주위를 돌면 투영이 바뀌어 거리 비율에 오차가 생긴다.
  크지 않지만 0은 아니다
- **리플레이·슬로모션** — 걸러내야 한다

## MVP — 두 축이면 고전적 스타일 지도가 나온다

3층이 막혀도 상관없다. **고전적 스타일 분류가 쓰는 축이 정확히 1층과 2층이기 때문이다.**

```
                        앞발 (밀고 들어감)
                              │
                              │
      스워머 ●                │                ● 슬러거
    (가까이 + 전진)            │            (중간 + 전진)
                              │
   가까움 ───────────────────┼─────────────────── 멂
                              │
                              │              ● 아웃복서
        ??? (비어 있어야 함)   │            (멀리 + 후퇴)
                              │
                        뒷발 (물러나며 유지)
```

### 축 1 — 선호 거리 (1층)

| 지표 | 내용 |
|---|---|
| 거리 중앙값 | 팔 길이 단위 |
| 거리 분포 모양 | 봉우리가 하나인가 여럿인가, 얼마나 퍼져 있나 |
| 구간별 체류 시간 | 밀착 / 근거리 / 중거리 / 원거리 비율 |

### 축 2 — 거리 주도권 (2층)

| 지표 | 내용 |
|---|---|
| 접근 주도 비율 | 거리가 줄어든 순간, 누가 움직였나 |
| 후퇴 주도 비율 | 거리가 늘어난 순간, 누가 움직였나 |
| 전진/후퇴 시간 비 | 앞발잡이인가 뒷발잡이인가 |

이 둘만으로 **아웃복서 / 슬러거 / 스워머 / 앞발·뒷발** 구분이 나온다.

4층(각도)은 어깨 좌표만 추가하면 되므로 2차로 붙인다.

## 검증 설계 — 이게 제일 중요하다

군집화의 가장 흔한 실패는 **의미 없는 군집이 나오는데 그럴듯해 보이는 것**이다.
그래서 검증을 먼저 설계한다.

**복싱에는 이미 전문가 라벨이 있다.** 아웃복서·슬러거·스워머는 수십 년간
합의된 분류다. 그러면 이렇게 할 수 있다.

### 1단계 — 예측을 먼저 적는다 (데이터 보기 전에)

| 예측 | 근거 |
|---|---|
| 아웃복서로 알려진 선수 → 거리 중앙값이 크고 후퇴 주도가 높다 | 도메인 정의 |
| 스워머로 알려진 선수 → 거리 중앙값이 작고 접근 주도가 높다 | 도메인 정의 |
| **뒷발 스워머 사분면은 비어 있다** | [Leather](https://leatherthegame.com/boxing-toolkit-categorising-styles/) 의 주장 — "back-foot swarmers rarely exist" |

세 번째가 특히 좋다. **구체적이고, 놀랍고, 틀릴 수 있다.**

### 2단계 — 맞는지 본다

- 맞으면 → 방법이 검증된 것이다. 그 다음 **기존 분류가 놓친 구조**를 찾는다
- 안 맞으면 → 측정이 틀렸거나 도메인 통념이 틀린 것이다. 둘 다 알 가치가 있다

### 3단계 — 그 다음에야 군집화

검증이 끝난 뒤에 비지도 군집화를 돌린다. 순서가 반대면 안 된다.
**먼저 군집을 만들고 나서 해석을 붙이면 무슨 말이든 갖다 붙일 수 있다.**

## 데이터 — 이게 진짜 비용이다

스타일 분류에는 **선수가 많이** 필요하다. 한 명당 여러 라운드도 필요하다.

| 항목 | 어림 |
|---|---|
| 최소 선수 수 | 20~30명 |
| 선수당 라운드 | 3라운드 이상 |
| 총 처리 분량 | 200라운드 내외 |
| 계산 시간 | 라운드당 3~5분 → 십여 시간. 감당 가능 |
| **진짜 비용** | **영상 찾기, 컷 처리, 추적 품질 확인** |

계산은 문제가 아니다. **사람 손이 드는 부분이 병목이다.**

선수 선정 기준: 스타일 라벨이 명확히 알려진 선수를 우선한다.
검증 단계에서 정답지로 써야 하기 때문이다.

## 단계

1. **컷 전환 처리** — 중계 영상에서 앵글이 바뀌는 지점을 잡고 추적을 다시 붙인다
2. **거리 정규화를 팔 길이 단위로** — `docs/spatial-concepts.md` 참고
3. **선수 5명으로 소규모 시험** — 스타일이 극명히 다른 5명. 예측이 맞는지 먼저 본다
4. **어깨 좌표 추가** — 4층(각도) 열기
5. **규모 확대 + 군집화**

3번이 분기점이다. **5명으로 예측이 안 맞으면 규모를 키워도 소용없다.**
