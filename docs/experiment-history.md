# 실험 기록

## 목적

이 문서는 구현물을 보존하기보다 어떤 가설을 시험했고 무엇을 배웠는지 기록한다. 프로젝트의 완료 조건은 모델 벤치마크가 아니라 개인 스파링 의사결정 루프의 유용성이다.

## 1. Gemini 전체 영상 분석

- 날짜: 2026-07-10
- 모델: `gemini-3.5-flash`
- 입력: 개인 스파링 영상 `IMG_0574.mp4`
- 결과: `results/IMG_0574.analysis.json`
- 사용자 검토: `results/IMG_0574.feedback.md`

### 맞은 부분

- 움직임이 주로 직선적이라는 전체 요약
- 후반에 상대 연타 압박을 계속 허용한 흐름
- 압박 상황에서 측면 탈출이 늦다는 후보 패턴

### 틀린 부분

- 사용자가 잽을 한 구간을 상대 공격과 사용자 방어로 반대로 설명
- 이미 거리가 멀고 상체를 뒤로 뺀 장면을 덕킹으로 설명
- 세부 오류에도 높은 확신도를 부여

### 해석

큰 흐름이 맞았다는 사실만으로 시간적 사건을 정확히 관찰했다고 볼 수 없었다. 잘못된 원자적 사건을 근거로도 그럴듯한 상위 패턴을 만들 수 있으므로, VLM 결과를 단독 사실 판정으로 사용할 수 없다.

## 2. 관찰 우선 프롬프트와 느린 클립

첫 피드백을 반영해 다음을 추가했다.

- 관찰 사실과 해석 분리
- 공방 시작 주체 명시
- 덕킹, 슬립, 린백, 거리 밖 회피의 구분 기준
- 불확실성 이유와 성공/실패 관찰 조건
- 전체 영상과 0.5배속/0.25배속 클립 비교

프롬프트는 과도한 단정을 줄였지만, 같은 장면의 세부 동작과 선후관계가 실행에 따라 달라졌다. 느린 영상도 오답을 일관되게 제거하지 못했다.

## 3. BoxingWeb 펀치 VLM 파일럿

BoxingWeb test 분할에서 겹치는 공방을 피한 48개 균형 클립을 만들었다. Gemini 무료 할당량 안에서 6개 샘플을 각 3회, 총 18회 평가했다.

| 지표 | 결과 |
| --- | ---: |
| 기술 분류 정확도 | 11.1% |
| 공격 선수 정확도 | 72.2% |
| 기술+공격 선수 정확도 | 11.1% |
| 반복 기술 일치도 | 83.3% |
| high confidence 응답 | 16/18 |
| high confidence 기술 정확도 | 12.5% |

샘플이 작고 한 기술 클래스가 포함되지 않아 일반화된 성능 수치로 볼 수는 없다. 그러나 같은 오답을 반복해도 확신도가 높을 수 있다는 위험은 확인했다. 48개 전체 평가는 프로젝트 핵심을 직접 검증하지 않고 비용 대비 정보 증가가 작다고 판단해 중단했다.

## 4. 외부 근거와 구조 비교

- Gemini 기본 영상 처리는 빠른 동작에 불리한 낮은 시간 샘플링을 사용한다.
- Video LLM 시간 이해 연구는 정적 단서와 언어 선입견에 의존하거나 시간적 응답이 불안정할 수 있음을 보고한다.
- BoxMind, DeepStrike, MotionGuru는 공통적으로 탐지·추적·포즈·시간 모델로 사건과 지표를 먼저 만들고 상위 분석을 수행한다.
- BoxMind는 `atomic punch event -> technical/tactical indicator -> strategy` 계층을 명시한다.

## 5. 결론

폐기한 가설은 "범용 VLM이 영상을 직접 보고 세부 사건의 사실 판정과 전략 피드백을 함께 담당할 수 있다"이다. VLM 전체를 배제한 것은 아니다.

현재 결정은 다음과 같다.

```text
사실 관찰: 전용 CV와 시간 모델
상황 구성: 구조화된 이벤트와 상대 모션
의사결정 분석: 검증 가능한 시퀀스와 패턴
언어 표현: 필요할 때 VLM/LLM 보조
```

이 결정은 프로젝트 목표를 바꾼 것이 아니라, 목표에 필요한 관찰 근거를 더 신뢰할 수 있게 만드는 기술 전략 변경이다.
